# متجر شعيبيه — حزمة الربط الحقيقي

هذه حزمة تأسيس للانتقال من نموذج واجهة محلي إلى متجر يستخدم قاعدة بيانات Supabase. لا تحتوي على مفاتيح مشروعك أو رقم واتساب، ولا تصبح حية بمجرد فك الضغط.

## ما تم تجهيزه
- واجهة المتجر العربية RTL الحالية.
- تحميل المنتجات النشطة من قاعدة البيانات بدلاً من الاعتماد على القائمة التجريبية عند اكتمال الإعداد.
- حفظ الطلبات وتفاصيلها في جداول منفصلة، مع طريقة الدفع عند الاستلام.
- تسجيل دخول الإدارة عبر Supabase Auth.
- أدوار قاعدة البيانات: مدير `admin`، موظف قسم `staff`، مراقب طلبات `orders_monitor`.
- قيد الموظف على القسم المعيّن له في سياسات قاعدة البيانات.
- رابط واتساب للعميل/المتجر بعد تسجيل الطلب، بحسب الرقم الذي تضيفه في الإعدادات.

## خطوات التفعيل المطلوبة
1. أنشئ مشروعاً جديداً في https://supabase.com/ واختر كلمة مرور قوية لقاعدة البيانات واحتفظ بها خارج المحادثة.
2. من SQL Editor شغّل كامل الملف `supabase/schema.sql`.
3. من Project Settings → API انسخ Project URL و`anon`/publishable key فقط.
4. افتح `js/config.js` وضع القيم مكان `YOUR_PROJECT_ID` و`YOUR_SUPABASE_ANON_KEY`، ثم أضف رقم واتساب المتجر بصيغة دولية من دون علامة `+`.
5. من Authentication أنشئ أول مستخدم مدير ببريدك. بعد إنشائه، انسخ UUID الخاص به ثم نفّذ في SQL Editor:

   ```sql
   update public.profiles set role='admin', full_name='مدير متجر شعيبيه' where id='ضع-UUID-هنا';
   ```

6. انشر مجلد `shuaibiya_real` على استضافة تدعم المواقع الثابتة (مثل Netlify). استخدم HTTPS حتى يعمل تحديد الموقع الجغرافي.
7. اختبر طلباً تجريبياً، ثم راجع ظهوره في لوحة الإدارة قبل مشاركة الرابط مع العملاء.

## إنشاء الموظفين وتحديد الصلاحيات
أنشئ حساب الموظف من Authentication → Users. ينشئ المخطط ملفه تلقائياً بصلاحية `orders_monitor` الافتراضية. لتعيينه موظف قسم أو مراقب طلبات، نفّذ من SQL Editor كمدير قاعدة البيانات:

```sql
-- موظف قسم
update public.profiles set role='staff', assigned_category='ملابس' where id='UUID-الموظف';
-- مراقب طلبات
update public.profiles set role='orders_monitor', assigned_category=null where id='UUID-الموظف';
```

## حدود هذه الحزمة حالياً
- لم يتم إنشاء مشروع Supabase أو نشر الموقع؛ يلزم تنفيذ خطوات التفعيل بحسابك.
- يلزم إدخال رقم واتساب الصحيح في `js/config.js`.
- واجهة الإدارة الحالية تعرض الطلبات وتضيف المنتجات؛ إدارة الموظفين وتعديل/حذف المنتجات وتغيير حالة الطلبات ورفع الصور/الفيديو تحتاج استكمال واجهة الإدارة قبل الاعتماد التجاري الكامل.
- لا يوجد دفع إلكتروني؛ الطلبات تسجل كـ«الدفع عند الاستلام» فقط.
- لا تضع أبداً `service_role` key في ملفات المتصفح. استخدم مفتاح anon/publishable فقط.
- قبل التشغيل التجاري، يوصى بإضافة تحقق خادمي من تفاصيل الأسعار والمخزون ومعدل الطلبات ومكافحة الرسائل المزعجة، لأن سعر الطلب في الواجهة لا ينبغي اعتباره مصدراً موثوقاً للحساب النهائي.

## الملفات
- `index.html`: واجهة المتجر.
- `js/config.js`: إعدادات مشروعك ورقم واتساب.
- `js/backend.js`: الربط مع Supabase.
- `supabase/schema.sql`: الجداول وسياسات الوصول.
